Frequently Asked Questions

What is the aS.c AI Boiler Framework?

The aS.c AI Boiler Framework is a lightweight, high-performance framework for building modern WordPress websites using a minimal theme, a content synchronization plugin, and a standalone plugin for site design and content.

What are the benefits of the aS.c AI Boiler Framework?

The aS.c AI Boiler Framework accelerates development by enabling design, content, media, and SEO workflows to be performed directly on your desktop using agentic AI consoles and modern IDEs. All site assets and content are version-controlled in a Git repository and encapsulated into a single portable plugin, eliminating third-party plugin bloat and recurring premium licensing costs.

Why is page speed performance prioritized?

Prioritizing page speed significantly improves SEO rankings. This is achieved by eliminating the bloat associated with page builders, theme extensions, and assorted third-party plugins, replacing them with a minimal theme and a single custom plugin.

Can custom content and partials be managed in the WordPress dashboard?

Yes, pages, posts, custom post types, and partials are registered seamlessly and synced directly through the WordPress dashboard. This gives you the flexibility to use the familiar WordPress dashboard while continuing to manage content and design directly on your desktop.

How does the framework achieve content and metadata portability?

The framework supports custom post metadata and references attachments, related posts, and terms by portable slugs and filenames instead of volatile database IDs. Content manifests declare these relationships in Git, and the synchronization engine automatically resolves them to local IDs on import across development, staging, and production environments.

How does the framework make it easy to add a theme toggle?

The framework includes a built-in, cookie-persisted theme toggle that switches between light and dark modes with zero flash-of-wrong-theme (FOUC). Theme preferences are evaluated server-side in PHP during page generation, seamlessly integrated with CSS custom properties, and compatible with web server FastCGI and CDN edge caching by partitioning cache keys with the theme cookie.

All of this is completely set up for you and documented in the framework to make it easy to create and customize light and dark themes with AI assistance, including a ready-to-use AI prompt to cleanly remove it if you don't want it.
